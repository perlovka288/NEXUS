# Game Tracker 2.1

Библиотека игр с **автоматическим учётом времени**, прогрессом и датами. Окно Windows-приложения, значок в трее, данные лежат у вас на диске.

## Что нового в 2.1
- **База игр на RAWG.** Вкладка «База игр»: поиск и фильтры по платформе (PC, PlayStation, Xbox, Nintendo, macOS, Linux, Android, iOS), жанру и году, сортировка по популярности, рейтингу, новизне и Metacritic. Ключ RAWG уже встроен, ничего вводить не нужно.
- **Прогресс.** У каждой игры считается % прохождения: часы ÷ среднее время прохождения (данные RAWG). «Прошёл» = 100%. Можно задать вручную. В библиотеке под карточкой видна полоска прогресса.
- **Даты и реальные дни.** Дата начала ставится при первом запуске (или статусе «Играю»), дата окончания — при статусе «Прошёл». Обе можно поправить руками. Считается календарный срок и сколько дней вы реально играли.
- **Вкладка «Статистика» на странице игры:** прогресс, начало, конец, календарный срок, реальные игровые дни, среднее за день, число и длина сессий, график за 30 дней, последние сессии, платформы, жанры, Metascore.
- **Wallpaper Engine больше не считается игрой** (и служебные компоненты Steam тоже). Если он уже попал в библиотеку, при запуске удалится сам.
- **Значок в трее** (область со стрелкой ^ в панели задач) и автозапуск вместе с Windows: приложение стартует свёрнутым и сразу считает время. Автозапуск включается сам при первом запуске, выключается в Настройках или в меню значка.

## Запуск
**Без установки:** запустите `Game Tracker.exe`. Если Windows покажет SmartScreen: «Подробнее → Выполнить в любом случае» (файл не подписан сертификатом).
Закрытие окна сворачивает приложение в трей, чтобы часы шли дальше. Выход: правый клик по значку → «Выход».

**Установщик для друзей:** установите Node.js 18+ (nodejs.org), запустите `resources\app\build-exe.bat`. В папке `resources\app\dist` появится `Game-Tracker-Setup-2.1.0.exe`. Друзья запускают его двойным щелчком: приложение ставится в профиль пользователя (права администратора не нужны), создаёт ярлыки и стартует.

**Если значка нет в трее:** Windows 11 прячет новые значки в область «^». Чтобы закрепить: Параметры → Персонализация → Панель задач → «Другие значки в области уведомлений» → включить Game Tracker. Либо перетащите значок из «^» на панель.

**Без Electron:** `resources\app\start.bat` (или `node server.js`) откроет сайт на http://localhost:8000.

Данные: `%APPDATA%\Game Tracker\data` (кнопка «Папка с данными» в Настройках). Там `library.json` (+ `.bak`), `config.json`, `meta.json` (кэш RAWG), `uploads` (ваши обложки).

## Как работает автоучёт
1. Читает установленные игры Steam (все библиотеки) и папки Epic, GOG, EA, Ubisoft, `X:\Games`, `X:\Игры` и ваши папки из Настроек.
2. Каждые 5 секунд смотрит запущенные процессы; для Steam-игр дополнительно читает запущенную игру из реестра Steam.
3. Нашло игру, которой нет в библиотеке → ищет в Steam по названию (иначе создаёт свою), добавляет, ставит «Играю».
4. Пока игра запущена, часы растут и пишутся по дням. Закрыли → записывается сессия (хранятся последние 500).
Лишнюю программу исключите в Настройках → «Не учитывать».

## Ключи (бесплатно)
- RAWG: https://rawg.io/apidocs — уже встроен общий ключ (лимит бесплатного плана 20 000 запросов в месяц на ключ, на всех пользователей сразу). Если друзей много, пусть каждый вставит свой в Настройках.
- SteamGridDB (красивые обложки): https://www.steamgriddb.com/profile/preferences/api
- Steam Web API (импорт библиотеки и часов): https://steamcommunity.com/dev/apikey

Данные об играх: RAWG (rawg.io).
